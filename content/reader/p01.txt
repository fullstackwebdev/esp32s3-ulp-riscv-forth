Rows three to ten are the text. Row one is an inverse bar
with the app's name and the page number on it; row
twenty-two carries the keys that work right now. Nothing
is drawn below row twenty-four, because the harness
assumes a normal terminal and this machine cannot ask it
how big the window is. The width is seventy columns, not
eighty: that is the launcher's own constant and every app
inherits it, so an eighty-column layout would look ragged.
